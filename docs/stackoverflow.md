# Waiting for a human

I still occasionally feel nostalgic about the MPI discussions I had on Stack Overflow while learning parallel programming. There was a particular kind of satisfaction in getting unstuck: following a small example, understanding what each process knew, and finally seeing why the program behaved that way.

It belongs to the same era as the handwritten code in this museum — when a good answer from another human could turn a frustrating few days into a lesson that stayed with you.

The [numerical exhibit](../projects/numerical-methods/README.md) carries those ideas forward in a new implementation.
