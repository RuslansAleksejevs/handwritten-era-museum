# Courses behind the code

Alongside my mathematics studies, I took interfaculty courses at MSU and explored machine learning through practical assignments. The notebooks became a shelf of techniques I returned to, rather than a complete record of everything I studied.

## The surviving threads

| Thread | What survives in my source material | Public teaching material |
| :-- | :-- | :-- |
| Introduction to Deep Learning | Handwritten digit classification, CIFAR convolutional networks, transfer learning with Simpsons characters, and image segmentation | [The 2022 MSU interfaculty course](https://teach-in.ru/course/introduction-to-dl-neychev), taught by Radoslav Neychev and Tatiana Gaintseva |
| Practical ML | A sales-forecasting project described in my original README as using Delivery Club data: store/product histories, calendar features, lagged sales and linear regression | [Machine Learning for Applied Tasks, 2022](https://teach-in.ru/course/machine-learning-for-applied-tasks), taught by Sergey Artamonov; a relevant recovered course, with the exact project-to-course match still being checked |
| Neural networks for science | [Correlations in random data](../projects/machine-learning/random-correlations/README.md), linear models, feature engineering, convolutional networks, batch normalization and autoencoders in the `NN4science` notebooks | [MSU.AI](https://msu.ai/) and its [interfaculty teaching materials](https://msu.ai/mfk); the precise historical edition behind these notebooks is not yet established |

The public lecture dates identify editions of the courses, not my individual enrolment dates. The names and assignment topics connect the deep-learning notebooks to the corresponding teaching sequence; confirmation of the exact semester remains part of the historical reconstruction.

## A project worth restoring

The Delivery Club notebook is a particularly useful next exhibit: forecasting demand for a product at a store from past sales. It contains my preprocessing decisions and model code, with comments revisiting earlier mistakes. Its original training CSV is absent from the saved repository, so its old metric is not a reproducible result here.

The restoration should recover the task and permitted data, compare a seasonal baseline with a learned model, and evaluate on later dates. That would make a stronger exhibit than presenting an unexplained score. This project is not included in the current linear-classifier experiment.
