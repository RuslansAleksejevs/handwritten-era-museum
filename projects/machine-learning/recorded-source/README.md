# Source used for the recorded experiments

These are the exact **2026 reconstruction scripts** whose fingerprints appear in
the saved metrics for segmentation, transfer learning, autoencoders and forecasting.
They precede the later readability refactor. They are not handwritten historical exhibits.

The [manifest](manifest.json) records their hashes; the neighbouring chapter
directories contain the current readable implementations. The saved source and
its required data reader are included so this edition does not depend on another
repository or an earlier Git history.
