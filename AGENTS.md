# Working on this collection

This museum combines unchanged selections under originals/ with modern
reconstructions under projects/. Never edit historical exhibit text to fix bugs;
keep fixes in the modern layer and preserve the recorded fingerprints. Preserve the distinction between original evidence and new work.
Keep each chapter runnable and document what was actually tested. Never invent
historical dates, authorship, benchmark results, or successful model training.

Run `make check` before committing code. Keep the repository PRIVATE until the
owner explicitly approves publication. Never copy parent-project documents,
private audit reports, credentials, or personal notes into this Git history.

Source repositories are read-only. Each chapter documents its source and scope.
Prefer a small complete experiment to untested claims of broad functionality.

For new Codex-authored reconstruction commits, use an English commit message
and include `Co-authored-by: Codex <codex@openai.com>`. This records the owner's
choice on 2026-10-07. Do not rewrite historical commits or attribute unchanged
historical source code to Codex.
